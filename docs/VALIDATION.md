# Validation scope

Run the repository checks from its root:

```bash
python3 scripts/validate_repo.py
python3 -m unittest discover -s tests -v
```

The structure checker uses PyYAML (`requirements-dev.txt`). The five calculators and their tests use only Python's standard library.

## Structural checks

- Valid skill name/description and directory match.
- Required standalone README, source map and UI metadata.
- Skill default prompt and normal invocation policy.
- Markdown local-file links and required-reference isolation inside the skill folder.
- JSON example parsing and explicit synthetic-data notices.

These checks do not verify external web links or whether a source remains free. Run-time source access, document dates and data coverage must still be established by the research workflow.

## Financial and market-data behavior

The offline tests cover each-year growth versus CAGR; external-estimate metadata versus model assumptions; missing forecasts and incompatible accounting bases; a loss base; inclusive/strict thresholds; future-publication look-ahead; fiscal period alignment; current cap/share reconciliation; diluted per-share versus aggregate equity return; target-date annualization; nonpositive terminal income; and malformed numerical inputs.

Price/volume tests cover two-session crossings, prior-only volume/high windows, already-above-average false positives, insufficient history, zero-volume baselines, partial sessions, mixed adjustment bases, duplicate/future dates and impossible OHLC ranges.

Migrated-calculator tests cover insider grants/duplicates/private versus unknown purchase venue, split-adjusted holdings, separate option rows, incomplete holdings, duplicate reports, financing cash/debt effects, ownership versus share-count dilution and invalid offering inputs. All five documented command-line examples are executed.

## Independent workflow exercise

A separate evaluator used the completed skill instructions and raw synthetic requests without being given the intended answers. The exercise covered fundamental valuation, options activity, institutional/sovereign disclosures, sector flows and news sentiment.

Observed results included rejection of a growth candidate with one 2% revenue-growth year and a modeled third year; separation of aggregate equity appreciation from diluted per-share upside; refusal to infer opening bullish sweeps from chain data; adjustment of a 2-for-1 split before interpreting holdings; distinction between a bank rating and a purchase; reserve quantities versus price-driven values; fund returns versus creations; and deduplication of news with an unverified screenshot claim.

This exercise checks how the instructions handle common ambiguous evidence. It is not a live market screen, backtest, return forecast, or proof of complete source availability. No current stock recommendation is generated by the checked-in fixtures.
